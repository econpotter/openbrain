# Optional Schemas

Optional schemas add capabilities that are not required by the core openbrain
runtime. Each optional module should document:

- its purpose and prerequisites
- whether it changes core tables or only adds sidecar tables
- its installation order
- its compatibility with upstream OB1 concepts
- its verification steps

Potential modules will be evaluated after the core schema is stable. See
`docs/plans/B-ob1-adoption.md`.
